# Finora — Financial Management System

A modern financial management system designed to help users organize, monitor, and manage their personal finances through an intuitive and responsive interface.

## Overview

Finora is a web-based financial management platform developed to centralize financial information and simplify everyday financial organization.

The system provides tools for tracking income and expenses, managing credit cards, setting financial goals, monitoring budgets, and visualizing financial performance.

## Features

- **User Authentication:** Account registration, login, password recovery, and Google authentication.
- **Dashboard:** Financial overview with income, expenses, balances, and key indicators.
- **Income & Expenses:** Financial transaction management and history.
- **Credit Cards:** Card management, available limits, and expense tracking.
- **Financial Goals:** Creation and monitoring of financial goals.
- **Financial Planning:** Organization and monitoring of financial budgets.
- **Reports & Charts:** Visual analysis of financial data.
- **Settings:** User preferences and language configuration.
- **Cloud Database:** Data persistence and synchronization using Firebase Firestore.
